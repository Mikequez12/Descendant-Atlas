# Atlas-Extra

Atlas-Extra is an experimental framework included with Descendant Atlas. It provides developers with a simpler and more consistent way to interact with Descendant+ data, while also introducing optional features for players, including a cross-world progression system capable of transferring achievements, unlocked classes, items, and other supported data between worlds.
